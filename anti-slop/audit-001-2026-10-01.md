# Audit Anti-Slop: Permukaan Publik Fabriku

Tanggal: 1 Oktober 2026

Status: belum lolos pemeriksaan akhir. Laporan ini hanya mencatat temuan; kode aplikasi tidak diubah.

## Cakupan dan cara pemeriksaan

Audit mencakup beranda, blog, halaman privasi dan syarat, alur masuk/daftar/pemulihan akun, login admin, halaman berhenti/lanjut berlangganan, serta shell HTML aplikasi. Formulir checkout storefront diperiksa sebagai bukti alur data untuk menilai kecocokan kebijakan privasi. Audit visual menyeluruh untuk seluruh tema storefront yang dibuat merchant, dashboard setelah login, dan integrasi sosial belum termasuk.

Pemeriksaan meliputi pembacaan source dan rute, screenshot lokal pada lebar 320, 375, 640, 768, 1024, dan 1440 px untuk beranda serta 375 px untuk beberapa halaman lain, pemeriksaan rasio kontras, keberadaan metadata SEO, dan hasil build terakhir setelah perbaikan tanda baca di halaman kebijakan privasi. Logo tulisan memiliki kanal alpha dengan rentang 0 sampai 255.

Tidak ditemukan overflow horizontal pada ukuran yang diuji. Copy beranda cukup spesifik pada produksi, stok, produk, dan jasa; tidak ditemukan testimoni atau statistik yang dibuat-buat. Judul, deskripsi, canonical, dan metadata mesin pencari serta preview berbagi tersedia pada halaman utama, blog, dan legal. Pemeriksaan klik browser tidak dapat dinyatakan lulus: JavaScript preview lokal gagal hydrate karena aset diarahkan ke origin HTTPS lain dan diblokir CORS. Source tetap ditinjau manual. SSR tersedia dalam konfigurasi container, tetapi hasil HTML produksi tidak diuji pada audit ini.

## Temuan

### 1. P1: Kebijakan belum menjelaskan pemrosesan data fitur website usaha

`resources/js/pages/Legal/Terms.vue:15,27` masih mendeskripsikan Fabriku sebagai aplikasi manajemen produksi dan penjualan, tanpa menyebut pembuatan atau penerbitan website usaha. `resources/js/pages/Legal/Privacy.vue:15,30-64` mencantumkan data tenant dan beberapa penyedia, tetapi tidak menjelaskan data pengunjung storefront maupun pemrosesan template lewat Satsetui. Kedua dokumen menyatakan terakhir diperbarui 27 Juli 2026.

Ini bukan sekadar ketidakcocokan copy. Form checkout (`resources/views/storefront/pages/cart.blade.php:35-40`) menerima nama, nomor WhatsApp, email, alamat, dan catatan. Integrasi Satsetui mengirim ID pengguna, ID site, email, dan nama (`app/Services/SatsetuiTemplateClient.php:12-34`). Pengunjung dan pengguna perlu mendapat penjelasan yang akurat tentang data, tujuan, retensi, dan pihak pemroses. Minta pemilik produk/legal meninjau isi sebelum rilis; jangan menebak redaksi hukumnya.

### 2. P2: Pemilih akun demo tidak sepenuhnya bisa digunakan dengan keyboard

Di `resources/js/pages/Auth/Login.vue:168-169`, tombol pembuka akun demo menghapus outline fokus tanpa pengganti yang terlihat. Kartu akun di baris 208 dan seterusnya adalah `div` dengan handler `@click`, tanpa semantik atau perilaku tombol. Pengguna keyboard tidak dapat melihat fokus pada pembuka dan tidak dapat memfokuskan atau memilih kartu demo.

Gunakan tombol native untuk setiap aksi, hubungkan pembuka dan panel dengan `aria-expanded`/`aria-controls`, lalu sediakan indikator `focus-visible` yang jelas.

### 3. P2: Kontras placeholder dan batas kolom formulir terlalu rendah

Kelas `placeholder-gray-400` dan `border-gray-300` dipakai berulang pada form masuk, daftar, reset password, dan pendaftaran Google. Pengukuran warna Tailwind yang dipakai menghasilkan:

- Placeholder `#9CA3AF` pada putih: **2,54:1**, di bawah 4,5:1 untuk teks biasa.
- Batas input `#D1D5DB` pada putih: **1,47:1**, di bawah 3:1 untuk pembeda komponen.

Label input memang tersedia, tetapi placeholder sulit terbaca dan bentuk kolom pada kartu putih sulit dibedakan. Naikkan kontras keduanya dan ukur ulang semua state, termasuk error dan fokus.

### 4. P2: Tombol tampil/sembunyikan password lebih kecil dari target sentuh

Tombol ikon di `resources/js/pages/Auth/Login.vue:120`, `resources/js/pages/Auth/Register.vue:203,231`, dan `resources/js/pages/Auth/ResetPassword.vue:73,101` tidak punya ukuran minimum atau padding tombol. Area klik mengikuti ikon 18-20 px, di bawah target minimum 24 px dan jauh di bawah target 44 px yang lebih nyaman untuk sentuhan. Pertahankan label aksesibelnya, tetapi besarkan area tombol.

### 5. P2: Instruksi noindex belum konsisten untuk halaman utilitas dan kampanye

Login, daftar, dan pelengkapan pendaftaran Google memakai `SeoHead` dengan `noindex`. Sebaliknya halaman lupa/reset password, verifikasi email, login admin, dan halaman kampanye memakai `Head` biasa atau HTML statis tanpa `noindex` (`resources/js/pages/Auth/ForgotPassword.vue`, `ResetPassword.vue`, `VerifyEmail.vue`, `EmailVerified.vue`; `resources/js/pages/Admin/Login.vue`; `resources/views/campaign/*.blade.php`). Ini membuat kebijakan indeks berbeda untuk halaman akun dan URL kampanye yang tidak dimaksudkan sebagai halaman pencarian. Tambahkan aturan noindex yang sesuai dan pastikan respons SSR memuatnya.

### 6. P3: Versi cache logo masih berbeda di halaman lama

Header publik dan alur akun sudah meminta aset `?v=3`, sementara halaman unsubscribe/resubscribe, email reset password, email kampanye, dan layout error masih meminta `?v=2`. Karena file logo telah diganti, URL lama dapat mempertahankan salinan lama di browser atau CDN. Samakan versi aset setelah memastikan semua template memakai file transparan yang baru.

### 7. P3: Tanda em dash masih tersisa di beberapa teks yang dapat dilihat pengguna

Perbaikan pada halaman privasi sudah menghapus sembilan em dash, tetapi pemindaian permukaan publik masih menemukan tanda tersebut di judul fallback `resources/views/app.blade.php:8`, judul `resources/views/campaign/unsubscribed.blade.php:6` dan `resubscribed.blade.php:6`, serta footer email kampanye `resources/views/emails/feature-campaign.blade.php:281`. Judul fallback mungkin tertimpa metadata Inertia saat SSR aktif; judul halaman kampanye dan teks email tidak. Ini temuan kecil dibanding isu aksesibilitas dan kecocokan kebijakan, tetapi berarti pembersihan tanda baca belum menyeluruh.

### 8. P3: Login admin masih memakai template lama dan bahasa Inggris

`resources/js/pages/Admin/Login.vue` masih menampilkan latar gradien ungu, panel glassmorphism, serta label seperti “Platform Management Dashboard”, “Remember me”, dan “Sign in to Admin Panel”. Halaman ini bukan halaman pemasaran untuk calon pelanggan, tetapi URL-nya publik dan terasa berbeda dari identitas serta bahasa Indonesia di halaman publik lain. Tentukan apakah layar staf memang sengaja dipisahkan; bila tidak, selaraskan tipografi dan bahasa.

### 9. Catatan proses: arah visual belum tercatat sebagai Design Read

`docs/new-plan/brand-seo-expansion-plan.md:21` hanya menyatakan identitas logo, warna, dan tipografi lama dipertahankan, serta audit visual dilakukan setelah posisi produk disetujui. Dalam rencana yang diperiksa tidak ada dials visual yang mencatat energy, rhythm, atau motion. Karena itu saya tidak bisa menyatakan implementasi ini sudah memenuhi seluruh proses Anti-Slop, walaupun beberapa hasil visual dan copy lolos pemeriksaan dasar.
