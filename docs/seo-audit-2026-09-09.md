## CRITICAL

### 1. SSR mati di produksi — semua tag SEO hanya ada di client-side

`config/inertia.php` menyetel `ssr.enabled = true` dan `resources/js/ssr.ts` + entri `ssr` di `vite.config.ts` sudah ada, tapi:

- `Dockerfile:72` menjalankan `npm run build`, bukan `npm run build:ssr` → `bootstrap/ssr/ssr.mjs` tidak pernah dibangun.
- `docker/supervisord.conf` hanya punya `apache2`, `laravel-worker`, `laravel-scheduler` — tidak ada program `inertia:start-ssr`, dan runtime image tidak punya Node.
- Akibatnya setiap request Laravel mencoba `http://127.0.0.1:13714`, gagal, lalu fallback ke render klien.

Bukti dari HTML mentah produksi:

```
$ curl -s https://fabriku.web.id/blog/cara-menghitung-harga-jasa-servis-kecil-agar-tidak-rugi \
  | grep -o 'rel="canonical"\|application/ld+json\|property="og:[a-z]*"\|name="description"' | sort | uniq -c
(kosong)
```

Nol canonical, nol JSON-LD, nol Open Graph, nol meta description di HTML server. `SeoHead.vue` benar, tapi outputnya baru muncul setelah JS jalan.

Bukti silang dari Ubersuggest (crawler-nya tidak eksekusi JS) — 19 dari 19 halaman kena:

| Isu | Halaman | Impact |
|---|---|---|
| Low word count | 19 | High |
| Duplicate `<title>` | 19 | High |
| Tanpa H1 | 19 | Medium |
| Tanpa meta description | 19 | Medium |
| URL kurang SEO-friendly | 18 | Medium |

Empat dari lima isu itu satu akar: crawler cuma melihat shell `app.blade.php` — judul yang sama di semua halaman, tanpa body, tanpa H1.

Bukti ketiga: GSC melaporkan **tautan internal = 0** setelah 3 bulan. Googlebot memang me-render JS (22 halaman terindeks), tapi graf tautan internalnya tidak pernah terbentuk — sinyal bahwa penemuan link lewat rendering lambat/tidak konsisten.

Terdampak juga: preview link WhatsApp/Facebook/Twitter/LinkedIn (scraper mereka tidak render JS) → semua share tampil judul generik "Fabriku — Operasional UMKM dalam satu alur", bukan judul artikel. Sama untuk Bingbot dan crawler AI.

**Dua opsi perbaikan:**

- *Minimal, tanpa Node di runtime:* render meta di `app.blade.php` dari `$page['props']` (Inertia sudah mengoper objek page ke blade). Cukup untuk title/description/canonical/OG/JSON-LD per halaman di semua crawler. Tidak menyelesaikan H1/word count, tapi Google me-render itu sendiri.
- *Lengkap:* `npm run build:ssr` di Dockerfile, Node di runtime image, tambah `[program:inertia-ssr]` ke supervisord. Menyelesaikan kelima isu Ubersuggest sekaligus.

### 2. `/auth/google/callback` mengembalikan 500 ke Googlebot

GSC "Error server (5xx)" = 1 halaman: `https://fabriku.web.id/auth/google/callback` (crawl terakhir 30 Agu 2026, terdeteksi 5 Sep).

Terverifikasi: `curl https://fabriku.web.id/auth/google/callback` → **500**. `GoogleAuthController::callback()` memanggil `Socialite::driver('google')->user()` tanpa penjagaan; tanpa parameter `code` Socialite melempar exception yang tidak tertangkap.

Dampak: 5xx berulang menurunkan kepercayaan crawl untuk seluruh domain, dan log error produksi terisi sampah dari bot.

Fix: bungkus `->user()` dengan try/catch → redirect ke `login` dengan pesan error; plus `Disallow: /auth/` di `robots.txt`.

## HIGH

### 3. URL filter blog memakan hampir seluruh anggaran crawl

Dari 17 URL tidak terindeks, **13 adalah URL filter blog**:

- *Duplikat tanpa kanonis pilihan pengguna* (3): `/blog?tag=produksi`, `/blog?page=1`, `/?ref=artifisial`
- *Di-crawl, saat ini tidak diindeks* (8): 6 di antaranya `/blog?tag=…&page=1` / `/blog?category=…&page=1`, sisanya 2 artikel asli
- *Halaman dengan pengalihan* (4): 3 di antaranya `/blog?tag=…&page=1`, sisanya `http://fabriku.web.id/`

Canonical dari audit #1 sudah menunjuk ke `/blog` bare, tapi (a) hanya client-side (lihat #1), dan (b) canonical saja tidak menghentikan crawl. Google tetap menghabiskan crawl untuk kombinasi tag × page yang tak terbatas, sementara artikel asli menganggur di "crawled, currently not indexed".

Fix: `noindex,follow` pada `Blog/Index.vue` saat ada query `category`/`tag`/`page` — bukan mengganti canonical, melengkapinya.

### 4. `<html lang="en">` di situs berbahasa Indonesia

`APP_LOCALE=en` (`.env` dan `.env.example`) → `app.blade.php` merender `lang="en"` untuk konten yang 100% Bahasa Indonesia. Terverifikasi live. Menyesatkan targeting bahasa/negara.

Fix: `APP_LOCALE=id` di `.env` produksi.

## MEDIUM

### 5. `lastmod` sitemap untuk halaman statis selalu `now()`

`SitemapController::index()` memakai `now()` untuk home, `/blog`, `/privasi`, `/syarat-ketentuan` — setiap request melaporkan "baru saja berubah". Google akan belajar mengabaikan `lastmod` untuk domain ini, termasuk untuk artikel blog yang `lastmod`-nya benar (`updated_at`).

Fix: tanggal tetap (mis. tanggal deploy) atau hilangkan `lastmod` untuk halaman statis.

### 6. Canonical paginasi blog menunjuk ke halaman 1

`BlogController::index()` selalu mengoper `canonical = url('/blog')`, termasuk untuk `?page=2`. Artikel yang hanya muncul di halaman 2+ kehilangan jalur penemuan kanonis. Kecil sekarang (19 URL), tapi tumbuh seiring blog.

Fix: canonical = `url('/blog')` hanya kalau tidak ada filter/paginasi; kalau ada `page`, canonical ke URL berpaginasi itu sendiri (dikombinasi dengan #3 yang me-noindex-nya).

### 7. Interactivity 435 ms (Ubersuggest, desktop)

Load time 0,77 s (great) dan CLS 0,00 (great), tapi Total Blocking Time 434,9 ms — "needs improvement" (ideal < 200 ms). Konsisten dengan hidrasi Vue penuh di halaman marketing statis. GSC "Data Web Inti" masih belum punya field data.

## Urutan pengerjaan yang disarankan

1. Perbaiki 500 di `/auth/google/callback` (kecil, langsung, hentikan sinyal buruk).
2. `APP_LOCALE=id` (satu baris).
3. `noindex` untuk view blog terfilter (kecil, hentikan pemborosan crawl).
4. Meta server-side — pilih varian blade minimal atau SSR penuh. Ini yang membuka semua sisanya.
5. Rapikan `lastmod` sitemap dan canonical paginasi.
6. Setelah live: GSC → "Validasi perbaikan" untuk 5xx dan duplikat; recrawl Ubersuggest untuk konfirmasi skor on-page naik dari 40.
