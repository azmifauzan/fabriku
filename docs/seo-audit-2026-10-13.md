## Temuan

### P0 — Dua `<title>` di setiap halaman publik (bug)
`resources/views/app.blade.php:8` merender `<title inertia>Fabriku - Operasional UMKM dalam satu alur</title>` statis, lalu `@inertiaHead` (SSR) menambah `<title>` per halaman. HTML final punya dua title; title **pertama** selalu generik. Ini yang dibaca RankMySEO sebagai "Duplicate titles" di 24/58 halaman, dan berisiko Google memakai title generik di SERP → CTR rendah. Terverifikasi via curl ke `/`, `/blog`, `/blog/cara-menghitung-hpp-produk-umkm`, `/privasi`.

Fix: render title fallback hanya bila SSR tidak menghasilkan head (atau hapus fallback — client-side Inertia tetap set title untuk halaman non-SSR). Tambah test yang assert response publik hanya punya satu `<title>`.

### P1 — GA4 tidak bisa mengukur SEO
- 0 key event: tidak ada `sign_up` / `generate_lead`. Tanpa ini tidak bisa tahu apakah trafik blog menghasilkan pendaftaran.
- Data tercampur trafik aplikasi (`/inventory/visualization`, `/sales-orders`, `/dashboard` = page view terbanyak setelah `/`) — mayoritas pemakaian demo/tenant, bukan visitor marketing.
- Sumber `suaranetijen.id / sponsor` 36 sesi dengan engagement 5 detik.

Rencana: kirim event `sign_up` setelah registrasi sukses (password + Google), tandai sebagai key event di GA4; batasi tag GA ke halaman publik saja (atau set `content_group` = marketing/app) supaya laporan landing page bersih.

### P1 — `/blog?page=N` title & description sama dengan `/blog`
Canonical sudah self, tapi title/description identik. Tambah "– Halaman N" ke title/description saat `page > 1`.

### P2 — Konten tipis & keyword salah sasaran
- Post blog ~700–850 kata (termasuk nav/footer) — konten bersih kemungkinan ~500–650 kata. Kompetitor untuk query "cara ..." biasanya 1.200+ kata dengan contoh/tabel.
- Keyword dilacak di RankMySEO (`aplikasi toko`, `aplikasi stok barang dan penjualan`, `stok barang dan penjualan`) adalah head term — tidak realistis untuk authority 4 (lihat `seo-keyword-strategy.md`). Ganti tracking ke long-tail yang sudah dapat impresi: `laporan penjualan sederhana`, `cara menentukan harga jual produk kerajinan`, `cara menghitung harga jasa servis`, `cara menghitung hpp produk umkm`.
- Internal link sudah ada (2–3 link antar post per artikel) dan setiap post punya CTA register + 2 JSON-LD — oke.

### P2 — Tidak ada halaman komersial per kategori
Semua 19 artikel informational; satu-satunya halaman komersial adalah home. Belum ada landing per kategori (mis. `/aplikasi-konveksi`, `/aplikasi-stok-kosmetik`, `/aplikasi-bengkel`) yang bisa menangkap intent "aplikasi + niche". Ini bisa dibangkitkan dari `config/business.php` (terminologi per kategori sudah ada).

### P3 — Authority
3 referring domain. Perlu backlink dasar: direktori UMKM/SaaS Indonesia, profil Google Business, listing di Product Hunt/AlternativeTo, guest post di komunitas UMKM, cross-link dari properti sendiri yang relevan.

### Bukan masalah (jangan "diperbaiki")
- 45 noindex `/blog?tag=`/`?category=` — sengaja (audit 2026-09).
- 404 `/cdn-cgi/l/email-protection` — artefak Cloudflare Email Obfuscation; bisa dimatikan di dashboard Cloudflare bila mengganggu.
- "Unfriendly URL" (23) di RankMySEO — query string filter blog yang sudah noindex.
- `fabriku.web.id` → 301 ke `fabriku.id`: benar. `www.fabriku.id` tidak resolve — opsional tambah DNS + 301.
